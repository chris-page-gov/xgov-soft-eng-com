# Security

Report suspected vulnerabilities privately to the repository owner. Do not
include secrets, personal data, exploit payloads, or restricted source
material in a public issue.

All acquired content is untrusted input. The producer validates source shape,
identities, checksums and generated relationships before release. It does not
execute catalogued code. A successful build or an SBOM reference does not
establish that a repository is secure or affected by a vulnerability.

The owner authorised public publication on 28 October 2026. Release controls
and their limits are documented in docs/operations.md. No private security
reports are included in the public helper and issue inventory.
