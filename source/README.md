# Source register

- current.json identifies the admitted public feed and exact original receipt.
  snapshots/<sha256>.json preserves the downloaded bytes.
- security-helper-inventory.json records the dated review of nine public
  repositories, workflow/manifests and open issues on 28 October 2026.
  Titles are verbatim identifiers; bodies/contact details are not republished.
- upstream/ contains attributed public source evidence, never executed here.
- sbom-review/ contains the public quality summary and one small SPDX example,
  each with URL, retrieval date and SHA-256. A sample cannot establish estate
  coverage, applicability or vulnerability status.

The repository feed controls catalogue records. GitHub code/issues and the
resources website support research and are not silently merged into it.
The issue inventory is a dated review, not a live mirror or a statement that
there are no private security reports. See LICENSE_DECISIONS.md.

- contributors-inventory.json is a dated credits review of the nine community
  repositories, including automation and inherited fork history.
- current.json supplements bind the public SBOM quality report used for facets.
- history/index.json and content-addressed history/observations/ files are
  maintained on the separate history-data branch. They retain public handles,
  account types and counts, not emails. The release includes exactly the
  observations used in its build, including pending and unavailable states.
