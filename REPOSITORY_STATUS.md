# Repository status

Experimental producer, version 0.1.0, prepared on 28 October 2026.

Implemented: standard OKF scaffold, frozen public source, deterministic build,
search/facets, proposed domains/tasks, RDF JSON-LD, evidence assertions,
quality/change reports and a daily release workflow.

The initial snapshot has 24,137 rows, 24,068 distinct repositories, 212 hosting
accounts and 14,326 distinct repositories with SBOM paths. A path does not
verify freshness, completeness, resolved versions or vulnerability status.

Public GitHub publication and daily refresh were authorised by the owner.
This repository is independent of the community organisation and government.

Outstanding: complete Explorer consumer acceptance; domain-specialist review;
separate guidance admission; README/topic enrichment; immutable repository IDs;
dependency/advisory matching and applicability review. No vulnerability scan of
the catalogued repositories has been performed. The custom semantic profile
is experimental, not canonical Bundle Wiki v1 conformance or production assurance.
